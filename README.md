# AI Cyber Surveillance Toolkit

Network security monitoring toolkit with AI-driven intrusion detection, traffic analysis, and automated vulnerability scanning.

## Features

- Real-time network traffic analysis
- Machine learning based intrusion detection
- Port scanning and service enumeration
- Automated vulnerability assessment
- Alert dashboard with threat severity classification
- Packet capture and deep inspection

## Tech Stack

Python, Scapy, Scikit-learn, Flask, Nmap, Pandas

## Getting Started

### Prerequisites

- Python 3.8+
- pip

### Installation

```bash
git clone https://github.com/karthik-idikuda/AI-cyber-survilance-cyber-tool..git
cd AI-cyber-survilance-cyber-tool.
pip install -r requirements.txt
```

### Usage

```bash
python scanner.py --target 192.168.1.0/24
```
